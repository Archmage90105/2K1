# ДА или НЕТ — приложение для конкурса

Экран и пульт для испытания «Правда / Ложь». Участники сидят лицом к зрителям и поднимают таблички «ДА» или «НЕТ». На экране у каждого — фото в круге и кольцо жизней: за каждый неверный ответ гаснет один сегмент. Выбывшие получают место в рейтинге, в конце показывается итоговая таблица.

Работает полностью офлайн, в обычном браузере, без сервера и установки. Состоит из статических HTML, CSS и JS файлов.

## Быстрый старт

1. Скачайте или склонируйте репозиторий.
2. Откройте `control.html` в Chrome или Edge (пульт оператора).
3. Нажмите **«Открыть экран»**. Перетащите появившееся окно на проектор и нажмите `F` (полный экран).
4. Нажмите **«Настройки»**, чтобы добавить участников и вопросы (см. ниже).

> Пульт, экран и настройки должны быть открыты **в одном браузере и одном профиле**: окна обмениваются данными через `localStorage`.

## Как проходит игра

1. Оператор задаёт вопрос вслух (текст виден и на экране). Участники поднимают таблички.
2. Оператор вводит ответы участников на пульте.
3. Когда ответили все, нажимает **«Показать результат»**: на экране по очереди гаснут сегменты у ошибившихся.
4. **«Следующий вопрос»** — переход дальше. После последнего раунда кнопка меняется на **«Финал»** и показывается итоговый рейтинг.

Ответы на экране скрыты до показа результата, поэтому зрители и жюри не видят выбор оператора заранее.

### Горячие клавиши (работают и в окне пульта, и в окне экрана)

| Клавиша | Действие |
|---|---|
| `1`–`9` | ответ участника с этим номером: нет → ДА → НЕТ → нет |
| `Enter` | показать результат |
| `Space` | следующий вопрос / финал |
| `R` | сбросить ответы текущего вопроса |
| `F` | полный экран (только в окне экрана) |

Клавиши идут в то окно, где сейчас фокус. Если пульт не реагирует, кликните в его окно (при потере фокуса сверху появляется красная подсказка).

### Ручные правки

В строке участника на пульте: **−1 / +1** меняют жизни (например, по решению жюри), **«Вернуть»** у выбывшего возвращает его в игру. Ответ можно менять до нажатия «Показать результат». **«Новая игра»** сбрасывает всё.

### Правила окончания и рейтинг

Игра завершается, когда:
- выбыли все участники, или
- закончились вопросы, или
- остался один участник (отключается константой `END_WHEN_ONE_LEFT = false` в `shared.js`).

Порядок в рейтинге: сначала те, кто остался в игре; затем больше правильных ответов; затем тот, кто выбыл позже. Равные показатели дают одно и то же место. Место выбывшего участника показывается на его карточке сразу после выбывания.

## Участники и вопросы

### Через страницу настроек (рекомендуется)

`admin.html` (кнопка «Настройки» на пульте):
- добавление, удаление участников, имена и фото (клик по кружку; фото обрезается до квадрата 400×400);
- число жизней (1–5, одно на всех);
- вопросы: текст, правильный ответ, порядок;
- **«Сохранить»** — применяет настройки и начинает игру заново;
- **«Скачать копию (JSON)» / «Загрузить копию»** — резервная копия, в том числе для переноса на другой компьютер;
- **«Вернуть данные из файлов»** — сбрасывает настройки браузера к `data/*.js`.

Данные хранятся в `localStorage` браузера. Очистка данных браузера их сотрёт, поэтому перед конкурсом делайте копию JSON.

### Через файлы

Если в браузере ничего не сохранено, берутся значения по умолчанию:

- `data/players.js` — `id`, `name`, `photo`, `maxLives`
- `data/questions.js` — `text`, `answer` (`true` = ДА, `false` = НЕТ)

Фото кладите в `assets/players/`. Если файла нет, показывается первая буква имени.

## Экран зрителей

- Сцена фиксированного размера 1920×1080, масштабируется под любое окно 16:9.
- Раскладка подбирается автоматически: 1–3 ряда, чтобы аватары были как можно крупнее. Рассчитана на 1–10 участников, 4–5 в один ряд, 8–10 в два.
- Темп анимации потери жизни задаётся в `display.js`: `STEP_TOTAL`, `STEP_MIN`, `STEP_MAX` (мс на одного ошибившегося; чем их больше, тем быстрее шаг).

## Структура проекта

```
index.html      экран для зрителей
control.html    пульт оператора
admin.html      настройки участников и вопросов
style.css       стили экрана
shared.js       состояние, правила, рейтинг, горячие клавиши
display.js      отрисовка экрана и анимации
control.js      интерфейс пульта
admin.js        страница настроек
data/           участники и вопросы по умолчанию
assets/players/ фото (в git не попадают)
```

Как это работает: состояние игры (`localStorage`, ключ `quiz-state-v2`) меняется на пульте или клавишей на экране, а другие окна получают его через событие `storage`. Настройки лежат в ключе `quiz-config-v1`.

## Если что-то не работает

|       Проблема       |                              Что сделать                              |
|----------------------|-----------------------------------------------------------------------|
| Клавиши не реагируют |     кликнуть в нужное окно; клавиши идут только в окно с фокусом      |
| Экран не обновляется | убедиться, что окна в одном браузере и профиле, не в режиме инкогнито |
|       Нет фото       | проверить путь в `data/players.js` или загрузить фото через настройки |
|   Настройки пропали  |             очищены данные браузера: загрузить JSON-копию             |
|    Игра «застряла»   |                        «Новая игра» на пульте                         |
